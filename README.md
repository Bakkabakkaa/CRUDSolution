
Это учебное веб-приложение для управления контактами

В приложении можно создавать, редактировать и удалять контакты, просматривать список, а также искать и фильтровать данные. Дополнительно реализовал экспорт данных в PDF, CSV и Excel.

Проект построен с разделением на слои (Core, Infrastructure, UI). Бизнес-логика вынесена отдельно, работа с базой данных реализована через Entity Framework Core.

Также в проекте есть регистрация и авторизация пользователей.

Отдельно реализовал тестирование: есть unit-тесты для сервисов и контроллеров, а также integration-тесты. Использовал xUnit и Moq.
